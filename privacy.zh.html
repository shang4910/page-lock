🔒 Page Lock 隐私政策

最后更新：2025年1月 | 版本 1.0.0

概述

Page Lock（以下简称"本扩展"）是一个轻量级的 Microsoft Edge 浏览器扩展，用于锁定网页页面以防止意外编辑。本扩展不收集、存储或传输任何个人数据。

🔒 核心承诺

我们不会收集您的任何个人数据。所有设置均存储在您的本地浏览器中。

数据收集声明

不收集本扩展不收集任何用户数据，包括但不限于：

  • ❌ 个人可识别信息（姓名、地址、电子邮件、年龄等）
  • ❌ 健康信息
  • ❌ 财务和支付信息
  • ❌ 认证信息（密码、PIN码等）
  • ❌ 个人通信（电子邮件、短信、聊天记录）
  • ❌ 位置信息（IP地址、GPS坐标等）
  • ❌ 网络历史
  • ❌ 用户活动（点击、滚动、按键记录等）
  • ❌ 网站内容

权限使用说明

本扩展请求以下权限，仅用于实现核心功能：

activeTab

用于获取当前活动标签页信息，以便向当前页面注入锁定脚本和样式。此权限不会读取页面内容或浏览历史。

storage

用于保存用户的设置偏好，包括：

  • 是否显示锁定提示条
  • 自动锁定 URL 匹配规则
  • 默认锁定状态

所有数据通过 chrome.storage.local API 存储，仅保存在用户本地浏览器中，不会上传到任何服务器。

scripting

用于向当前页面注入内容脚本（content script）和样式表，实现页面锁定功能。脚本会拦截拖拽、输入、粘贴等事件，并移除可编辑属性。

<all_urls>

扩展需要在所有网页上运行锁定功能。用户可以在任意网页上手动触发锁定，或配置自动锁定规则。扩展不会主动访问或修改任何远程服务器上的数据。

远程代码声明

无远程代码本扩展不包含任何远程代码。所有 JavaScript 和 CSS 代码均打包在扩展包中，不引用任何外部脚本文件，不使用 eval() 执行动态代码，不加载任何外部模块。

第三方数据共享

不共享我们不会将任何数据出售或传输给第三方。由于本扩展不收集任何数据，因此不存在数据共享行为。

数据安全

由于本扩展不收集、存储或传输任何用户数据，不存在数据泄露风险。所有本地设置数据由浏览器原生存储机制保护。

政策更新

如果我们更新本隐私政策，将在 GitHub 仓库中发布更新版本。重大变更将通过扩展更新通知用户。
