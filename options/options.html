Page Lock 页面锁定扩展

Page Lock

版本 1.0.0

一个轻量级的 Edge 浏览器页面锁定工具。当你需要专注于阅读文档、防止意外编辑时使用。

🚫 禁止插入 阻止在页面中插入新内容
🚫 禁止拖拽 阻止拖拽页面元素
🚫 禁止编辑 将可编辑区域设为只读
✅ 允许复制 正常浏览和复制内容

使用说明

  1. 点击 Edge 工具栏上的 Page Lock 图标可以锁定/解锁当前页面
  2. 使用快捷键 Ctrl + Shift + L 快速切换
  3. 锁定后页面顶部会显示提示横幅
  4. 可以在设置中配置自动锁定规则
