Page Lock Privacy Policy

Last Updated: January 2025 | Version 1.0.0

Overview

Page Lock ("this extension") is a lightweight Microsoft Edge browser extension that locks web pages to prevent accidental editing. This extension does not collect, store, or transmit any personal data.

Core Commitment

We do not collect any of your personal data. All settings are stored in your local browser only.

Data Collection Statement

No CollectionThis extension does not collect any user data, including but not limited to:

  • Personally identifiable information (name, address, email, age, etc.)
  • Health information
  • Financial and payment information
  • Authentication information (passwords, PINs, etc.)
  • Personal communications (emails, messages, chat records)
  • Location information (IP address, GPS coordinates, etc.)
  • Web browsing history
  • User activity (clicks, scrolling, key presses, etc.)
  • Website content

Permission Justification

This extension requests the following permissions, solely to implement its core functionality:

activeTab

Used to get the current active tab information so that the locking script and styles can be injected into the current page. This permission does not read page content or browsing history.

storage

Used to save user preferences, including:

  • Whether to show the lock notification banner
  • Auto-lock URL matching rules
  • Default lock state

All data is stored via the chrome.storage.local API, saved only in the user's local browser, and is not uploaded to any server.

scripting

Used to inject content scripts and stylesheets into the current page to implement the page locking functionality. The script intercepts drag, input, and paste events, and removes editable attributes.

<all_urls>

The extension needs to run the locking functionality on all web pages. Users can manually trigger locking on any page or configure auto-lock rules. The extension does not actively access or modify any data on remote servers.

Remote Code Declaration

No Remote CodeThis extension does not contain any remote code. All JavaScript and CSS code is packaged within the extension, does not reference any external script files, does not use eval() to execute dynamic code, and does not load any external modules.

Third-Party Data Sharing

No SharingWe do not sell or transmit any data to third parties. Since this extension does not collect any data, there is no data sharing behavior.

Data Security

Since this extension does not collect, store, or transmit any user data, there is no risk of data leakage. All local settings data is protected by the browser's native storage mechanism.

Policy Updates

If we update this privacy policy, we will publish the updated version in the GitHub repository. Significant changes will be communicated to users via extension updates.
